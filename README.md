# HarmonyKite

Tracks multiple GitHub repositories and their dependencies across multiple projects with a centralized dashboard.

HarmonyKite is built to be simple and practical, focusing on doing one thing well.

**Why HarmonyKite?**

- Tracks multiple GitHub repositories and
- their dependencies across multiple projects
- with a centralized dashboard

## Key Features

- Tracks multiple GitHub repositories and
- their dependencies across multiple projects
- with a centralized dashboard

## Technology Stack

- javascript
- javascript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/HarmonyKite.git`
2. `cd HarmonyKite`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure HarmonyKite, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
